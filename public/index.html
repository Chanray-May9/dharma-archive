A PRACTICE, NOT A PROMISE

保存是一件持续的事

一

先保留原件

原始 XML、JSON 按字节保存在恢复包中，记录来源提交版本和校验值。纯文本是便于阅读的派生副本，不能代替原件中的校勘与结构。

二

不把钥匙交给网站

ZIP、TXT、JSONL、CSV 和纯文本恢复说明都能离线打开。前端或 API 消失后，直接从文件镜像、仓库或离线硬盘取回即可。

三

让副本分散存在

云端副本之外，还需要分处不同地点的离线硬盘或其他介质。定期核对校验值、试做恢复，并在介质或格式老化之前迁移。

关于“全部佛经”与千年留存

世界佛典没有一份完整且固定的数字总目录。本档案如实记录已经获取的文件，尚未覆盖的语种、手稿、图像和版本持续列入来源清单。云服务没有千年存续保证；长期保存依赖多方持有、持续维护和代际交接。
